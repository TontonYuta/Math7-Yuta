# Unslop Writing & UI Guidelines

Guidelines adopted from `cursor/plugins/.../unslop` to eliminate AI tells from UI text, code comments, and documentation:

1. **Delete AI Vocabulary**:
   - Avoid buzzwords: "crucial", "delve", "enhance", "fostering", "intricate", "pivotal", "showcase", "tapestry", "toàn diện", "vượt trội", "kỳ thú".
   - Use plain, direct words: "is", "has", "use", "solve", "open", "calculate".
2. **Remove Decorative Emojis**:
   - Strip random emojis from headings and status bullets unless serving as explicit game item icons.
3. **Say What It Does, Not How It Feels**:
   - Replace vague emotional descriptors with concrete instructions, numbers, or rules.
4. **Remove Sycophantic & Chatbot Phrasing**:
   - Do not use filler praise ("xuất sắc tuyệt đỉnh", "Great job!"). Provide factual completion feedback.
5. **Punctuation & Headings**:
   - Avoid em dashes; use periods or commas.
   - Use sentence case for labels and subheadings.
